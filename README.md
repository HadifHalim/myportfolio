> A clean, fully responsive, and interactive personal portfolio website showcasing my profile, enterprise networking skills, professional certifications, and projects.

---

## 🌟 Features

* **🌓 Dynamic Light/Dark Mode:** Features a custom theme toggle with smooth `cubic-bezier` transitions, animated icon rotation, and `localStorage` persistence across page reloads.
* **📱 Fully Responsive Layout:** Seamlessly adapts across desktop, tablet, and mobile displays with an animated hamburger navigation menu.
* **📜 Interactive Certificate Showcase:** Dedicated section for viewing and directly downloading verified certification PDFs (CCNP Enterprise, Cisco CyberOps, CCNA, IoT, etc.).
* **🎨 Modern UI/UX:** Built with sleek Google Typography (*Orbitron*, *Montserrat*, *Inter*), CSS custom variables, and card-based grid layouts.
* **⚡ Light & Fast:** Pure vanilla web technologies without heavyweight frameworks—ensuring instant page loads and high performance.

---

## 🛠️ Built With

* **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid)
* **Scripting:** Vanilla JavaScript (ES6+)
* **Hosting:** GitHub Pages
* **Fonts & Icons:** Google Fonts, Custom SVG/PNG Icons

## 📂 Project Structure

```text
myportfolio/
├── index.html          # Main HTML structure
├── style.css           # Global styles, CSS variables, theme transitions
├── mediaqueries.css    # Responsive design breakpoint overrides
├── script.js           # Theme toggle, localStorage logic, menu controls
└── assets/             # Profile pictures, certificate PDFs, and icons

```
